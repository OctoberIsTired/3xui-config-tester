3xui-tester конструктор эксперимента

Локальный конструктор тестовых конфигураций. Значения параметров выбираются множественно; токен панели в браузер не передаётся.

Подключение и временный inbound

Укажите адрес панели, исходный inbound и путь к Xray на этой машине. Токен панели задаётся переменной окружения PANEL_API_TOKEN перед запуском Web UI и не передаётся в браузер.

Порт тестовой копии должен быть доступен с машины, где запускается тестер. Для KCP нужен UDP. Проверка сертификата панели и TLS настройки тестового inbound независимы.

Что тестировать

Каталог загружается backend-ом из схем Xray/3x-ui и дополняется текущими значениями inbound через API панели. Кнопка «Копия inbound» создаёт точный фиксированный baseline; после этого переключите нужные параметры в «Мутировать».

План и метрики

Настройте объём эксперимента, условия допуска и набор измерений. Подсказка под каждым полем объясняет его влияние на запуск.

Кандидат отбрасывается после заданного числа неудач. Включённый замер скорости добавляет до 5 МБ трафика на каждый повтор.

Нажмите «Рассчитать план», чтобы увидеть число запусков и первые конфигурации.

Запуск проверки

Проверка создаёт временную копию входящего подключения на порту, указанном в разделе «Подключение». Рабочее подключение не изменяется; копия удаляется после завершения или остановки.
